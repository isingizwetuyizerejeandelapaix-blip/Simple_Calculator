# Simple Calculator

A command-line calculator built with Python for the Codveda Technologies Python Development Internship, Level 1.

## Features

- Addition, subtraction, multiplication, and division
- Operation selection through a simple menu
- Two number prompts for each calculation
- Division-by-zero handling with a clear error message
- Input validation for non-numeric values and invalid menu choices
- Repeated calculations until the user exits

## Requirements

- Python 3
- No third-party packages

## Run the calculator

From this folder, run:

```bash
python3 calculator.py
```

## Run the tests

The test suite checks the arithmetic functions, division by zero, menu selection, invalid inputs, and exit behavior:

```bash
python3 -m unittest -v
```
