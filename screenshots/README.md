# Screenshot checklist

Save genuine screenshots in this folder before publishing the repository:

1. `calculator-addition.png` — show the GUI with Addition selected, `50` and `20` entered, and the result `70` displayed.
2. `division-by-zero.png` — show the GUI with Division selected, `50` and `0` entered, and the error message displayed.
3. `tests-passed.png` — run `python3 -m unittest -v` in VS Code and show all five tests passing.

On macOS, use **Shift-Command-5** to capture the calculator window or the VS Code test results. Choose this folder as the save location for each image.
