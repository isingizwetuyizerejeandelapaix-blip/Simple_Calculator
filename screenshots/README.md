# Screenshot checklist

Save genuine VS Code screenshots in this folder before publishing the repository:

1. `calculator-addition.png` — run `python3 calculator.py`, choose Addition, enter `50` and `20`, and show the `70.0` result.
2. `division-by-zero.png` — run the calculator, choose Division, enter `50` and `0`, and show the error message.
3. `tests-passed.png` — run `python3 -m unittest -v` and show all four tests passing.

On macOS, use **Shift-Command-5** to capture the VS Code window or the relevant terminal area. Choose this folder as the save location for each image.
